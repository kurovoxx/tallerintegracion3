Sigma Academy

Sigma Academy es una aplicación web y de escritorio para la gestión académica personal y la colaboración entre estudiantes: asignaturas, apuntes, grupos de estudio, tareas y reuniones.

Es un proyecto universitario (capstone). La aplicación solicita acceso a tu cuenta de Google únicamente para respaldar los apuntes que tú creas en tu propio Google Drive (carpeta Apuntes TI3) y, si lo autorizas, crear eventos en tu calendario.
